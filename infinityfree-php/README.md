# متجر نُقطة — PHP + MySQL لـ InfinityFree

## النشر

1. أنشئ قاعدة MySQL في InfinityFree واستورد `schema.sql` عبر phpMyAdmin.
2. راجع بيانات الاتصال في `config.php`.
3. ارفع جميع الملفات إلى `htdocs`، بحيث يكون `index.php` داخل `htdocs` مباشرة.
4. افتح الموقع واختبر إضافة منتج ثم إنشاء طلب.

## لوحة الإدارة

افتح `admin-login.php`.

- اسم المستخدم الافتراضي: `admin`
- كلمة المرور الافتراضية: `ChangeThisAdminPassword123!`

غيّر `ADMIN_PASS` داخل `config.php` قبل النشر إلى كلمة مرور قوية وفريدة. لوحة الإدارة تسمح بإضافة وحذف المنتجات وتحديث حالات الطلبات.

## WhatsApp

عدّل `WHATSAPP_NUMBER` في `config.php` إلى رقمك بصيغة دولية دون علامة `+` أو مسافات، مثل `9665XXXXXXXX`. سيظهر رابط تأكيد WhatsApp بعد إنشاء الطلب.

## المزايا

كتالوج عربي RTL، بحث، تصنيفات، صفحات تفاصيل المنتجات، سلة مشتريات، طلبات محفوظة في MySQL، لوحة إدارة، وتأكيد عبر WhatsApp. الأسعار مخزنة بالهللات وتظهر بالريال السعودي.

لا ترفع `config.php` إلى مستودع عام، ولا تشارك بيانات قاعدة البيانات. غيّر كلمة مرور قاعدة البيانات إذا ظهرت في مكان عام ثم حدّثها في `config.php`.
