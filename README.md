# matjar-nuqta-project2
وصف متجر نُقطة نُقطة هو متجر إلكتروني عالمي يجمع لك كل ما تحتاجه في مكان واحد، بتجربة تسوق عربية سهلة وأنيقة. يوفر المتجر مجموعة متنوعة من المنتجات تشمل الملابس الولادية والرجالية والنسائية وملابس المواليد، بالإضافة إلى الأواني ومستلزمات المنزل والتنظيف والعناية، الأحذية والحقائب، التحف الفنية، الإلكترونيات، والهدايا والمناسبات.
